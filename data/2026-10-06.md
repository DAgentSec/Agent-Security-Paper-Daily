### [1] [Blocking at the Boundary: Auditing Long-Horizon Agents against Staged Prompt Injection](https://arxiv.org/abs/2610.05163)
*Jingkai Liu, Yufei Han, Xiaoting Lyu, Wei Wang, Ting Yu*

Catalog: Agent Sec | Source: arXiv

TL;DR: 该论文提出“分阶段提示注入”攻击与“边界动作审计”任务，并设计免训练的Path-Aligned Attribution（PAA）审计器，在关键动作生效前高召回、低误拦地阻断长程智能体中的间接提示注入。


<details>
  <summary>Details</summary>
Motivation: 长程智能体会读取外部内容、调用工具并修改持久状态，间接提示注入可在因果相连的多个阶段中传播，并在工作流继续运行时悄然改变关键动作；现有输入筛查、事后评估与动作前检测方法无法定位干预点，或存在单位与标签不兼容问题，因此需要在每次关键动作执行前做出通过/阻断决策。

Method: 构建自动化、反馈引导的攻击生成流水线，在Claude Code与Codex原生运行时实施攻击；将防护形式化为边界动作审计：给定初始上下文、轨迹前缀与待执行的完整消息或工具调用，预测Pass或Block；配对攻击与良性执行，构建479对、3,112单元基准；提出免训练的PAA，将待执行动作拆解为操作性元素，追踪每个取值的来源与决策依据，仅当某元素受到攻击者可触达来源的不当实质影响（无条件引导或与可见证据冲突）时才阻断。

Result: 确认攻击覆盖8种工作流场景、7类攻击目标、6种注入面；在Claude Sonnet 5后端、全基准fail-open评分下，PAA达到86%阻断召回率与6–8%误拦率（FBR），而ARGUS为44–47%召回率、16–33%FBR；在三者均原生支持的工具调用上，PAA召回率高于VIGIL与ARGUS且FBR更低，所有配对95%置信区间均不含零。

Conclusion: 生产级长程智能体易受上下文感知的多步分阶段提示注入；边界动作审计与PAA能在动作生效前有效定位并阻断攻击，在召回与误拦权衡上优于现有方法。

Indirect prompt injection can exploit task-specific context, propagate across causally connected stages, and alter a consequential action while the workflow continues; we term this staged prompt injection.

The confirmed attacks span eight workflow scenarios, seven attack goals, and six injection surfaces, showing that production agents are vulnerable to context-aware, multi-step injection over long horizons. Stopping such attacks requires a decision before each consequential action: input screening and completed-run evaluation cannot locate the intervention point, and existing pre-action methods use incompatible units and labels. We therefore formulate boundary action auditing: given initial context, a trajectory prefix, and a fully specified pending message or tool call, an auditor predicts Pass or Block before its effect occurs.
