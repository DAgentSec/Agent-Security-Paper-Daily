### [1] [Poisoned Skills: Propagating Jailbreaks Through Agent Markdown Files](https://arxiv.org/abs/2610.37738)
*Kashyap R Manjusha, Murali Emani*

Catalog: Agent Sec | Source: arXiv

TL;DR: 研究表明，用户提供的 Markdown 技能文件可作为越狱注入通道，使基于 LangChain 的问答 agent 的平均攻击成功率从 0.5% 升至 45%，单模型最高达 68.9%。


<details>
  <summary>Details</summary>
Motivation: 现代 agent 框架在初始化时会把用户提供的 Markdown 文件（系统提示、工具描述、技能定义如 SKILL.md）拼装进上下文；这类配置机制是否同时构成提示注入与越狱通道，此前缺乏系统评估，属于未被充分认识的安全面。

Method: 作者构建了一个基于 LangChain 的问答 agent，其系统提示由用户 Markdown 文件动态组装；将“人格操纵 + GPTFUZZER 变异”组合的越狱载荷嵌入技能文件，在 7 个当代开放权重模型上以覆盖 9 类危害范畴的 270 个禁忌问题评测；并对比两种载荷混淆策略：基于零宽字符的隐形载荷与基于字素-音素（grapheme-to-phoneme）转换的语音载荷。

Result: 良性系统提示下模型近乎完全拒答，平均 ASR 仅 0.5%；注入技能文件后平均 ASR 升至 45%，单模型最高 68.9%。两种混淆策略均未超过明文注入，其中语音载荷反而把平均 ASR 压到 30%。

Conclusion: Markdown 技能文件是 AI agent 中一个尚未被充分探索的攻击面；配置型越狱的易感性更多取决于底层模型本身，而非具体的载荷混淆技巧。

Abstract: Modern agent frameworks allow users to provide Markdown files containing system prompts, tool descriptions, and skill definitions (e.g., SKILL.md), which are incorporated into the agent's context during initialization. In this work, we investigate whether this configuration mechanism can also serve as an injection channel: can a jailbreak embedded in a Markdown skill file propagate through an agent and induce prohibited behavior? To answer this question, we construct a LangChain-based question-answering agent whose system prompt is assembled from a user-provided Markdown file. We embed a jailbreak combining persona manipulation with a GPTFUZZER-based attack and evaluate its effectiveness across seven contemporary open-weight models using 270 forbidden questions spanning nine harm categories. Under a benign system prompt, the models exhibit near-complete refusal behavior, with a mean attack success rate (ASR) of just 0.5%. In contrast, the injected skill file raises the mean ASR to 45%, reaching 68.9% for individual models. We further evaluate two payload obfuscation strategies: an invisible zero-width character-based stealth payload and a phonetic payload based on grapheme-to-phoneme transformations. Neither outperforms the plain-text injection; notably, the phonetic variant reduces mean ASR to 30%. These findings identify Markdown skill files as an underexplored attack surface for AI agents and suggest that vulnerability to configuration-based jailbreaks depends more strongly on the underlying model than on the specific payload obfuscation technique.

### [2] [Agentic Backdoors via Pretraining Poisoning](https://arxiv.org/abs/2610.37741)
*Xinyan Hu, Pingbang Hu, Chloe Loughridge, Xuanli He, Nicholas Carlini, Matthew Jagielski, Javier Rando, Yiming Zhang*

Catalog: Agent Sec | Source: arXiv

TL;DR: 该论文首次证明，在预训练语料中投毒可向CLI智能体植入远程代码执行后门，并在Qwen3系列上端到端验证该威胁会随模型规模放大。


<details>
  <summary>Details</summary>
Motivation: 大语言模型依赖从公开网络抓取、未经筛选的语料进行预训练，攻击者可在其中植入 poisoned content；此前尚缺乏证据表明这种投毒能在部署后的智能体中植入可执行任意命令的远程代码执行后门，因此需要端到端评估其真实安全风险。

Method: 作者从零预训练Qwen3 0.6B、1.7B和4B模型，并使用干净流水线将其后训练为CLI智能体；仅用新设计的投毒样本污染0.1%的预训练语料，再检测智能体在触发条件出现时是否执行攻击者指定命令、在干净输入上是否保持正常行为。

Result: 投毒成功植入后门：触发时智能体执行恶意命令，干净输入下表现正常；攻击成功率随模型规模上升，4B模型在0.1%投毒率下达到约92% ASR，即使投毒率降至0.0005%仍保持为正。

Conclusion: 预训练数据投毒可植入能穿过干净后训练流程的持久性远程代码执行后门，构成严重的模型供应链安全风险，且更大模型可能带来更高攻击成功率。

Abstract: Large language models are pretrained on vast, uncurated corpora scraped from the public web. This creates a security risk from attackers who plant poisoned content in the pretraining data. We show for the first time that such poisoning can plant a remote code execution backdoor in an agent, causing it to execute attacker-chosen commands on the user's machine. To measure the threat end to end, we pretrain Qwen3 models from scratch at sizes 0.6B, 1.7B, and 4B, and then post-train each into a CLI agent using a clean pipeline. Poisoning only 0.1% of the pretraining corpus with our new poison design implants the backdoor: the deployed agent executes the malicious command when the trigger is present while behaving normally on clean inputs. The attack success rate (ASR) increases with model scale, with the 4B model reaching roughly 92% ASR at a 0.1% poison rate and staying positive even when the poisoning rate drops to 0.0005%. Our code is available at https://github.com/safety-research/agentic-backdoor.

<details>
  <summary>Details</summary>
Motivation: 类型化决策模型以单次快速廉价查询直接输出决策，已用于安全敏感任务，但现有自适应攻击未利用其速度优势，且缺乏对通用对抗样本的系统研究。

Method: 在代表性类型化决策模型Jev上，设计无需攻击者语言模型的快速黑盒查询式攻击，在12个不同数据类型与应用场景的数据集上搜索短对抗后缀，并测试其通用性与跨任务迁移性。

Result: 常见提示注入在10,240次配对测试中均未改变正确答案；相反，该方法可在数分钟内找到翻转高置信答案的短后缀，每个数据集一个后缀可翻转43%的未见文档，且从一个任务生成的后缀可在其他任务中翻转90-100%的样本。

We fill both gaps on Jev, the representative typed decision model, with a quick black-box query-based attack that calls no attacker language model. We conduct extensive experiments on 12 datasets with different data types and application scenarios. The results show that Jev resists common prompt injections: no strategy changes a correct answer in 10,240 paired tests. In contrast, our attack finds short suffixes that flip confident answers within minutes. These suffixes are universal: one suffix per dataset flips 43% of unseen documents. Because typed decision models, unlike classic NLP models, can serve many tasks, we test whether these suffixes transfer across tasks. We find that one suffix generated from one task can flip 90-100% of the samples in other tasks. We therefore believe the evaluation of typed decision models must include strict adaptive attacks to fully reveal their robustness.

The code is available at https://github.com/SaFo-Lab/Evolve-IPI

  <summary>Details</summary>

Our code and datasets are publicly available at https://github.com/Mdniloykhan/jailbreak-eval-7llms.
